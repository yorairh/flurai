## FluRai 0.8.0: Grammar (milestone 7)

### New
- **Learn → Grammar:** 47 grammar points, 25 for N5 and 22 for N4, each with its meaning, how to build it, an explanation written for FluRai and example sentences.
- **Practice:** fill-in-the-blank exercises. Practise one point, or ten mixed points from a level (points you don't know yet come first). After each answer you see which point it tested.
- **Status per point:** New, Learning, or Known (three right answers, the latest one right). Each level shows how many points you know.
- Grammar practice counts toward your daily study time and streak.
