## FluRai 0.1.0: Project setup (milestone 0)

The first runnable version of the app: the shell everything else is built in.

### What's in it
- Kotlin + Jetpack Compose app for Android 8.0+
- Bottom navigation with four tabs: **Home, Learn, Explore, Me**. Each tab previews the features planned for it.
- FluRai look: indigo, vermilion and matcha on washi-paper tones, in light and dark mode
- Japanese text is rendered with Japanese (not Chinese) glyph shapes on any phone language
- App icon: 流 (ryū, "flow", as in 流暢, fluent)

PR: #1

**Install:** download the APK below and open it on your phone (allow installs from unknown sources). Releases are signed with the FluRai release key; a test build signed with the old debug key must be uninstalled first.
