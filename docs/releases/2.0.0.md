# FluRai 2.0.0

**New**
- The word library is now a full Japanese dictionary: search finds any word in JMdict (over 200,000 entries), not only the JLPT lists. Words outside the lists are marked "Not JLPT", and you can open them, add them to your flashcards or put them in a deck like any other word. Many of them come with an example sentence.
- Progress shows an "Other words" line for words you study that aren't on the JLPT lists. They don't count toward a level, but the kanji you learn through them do count in kanji coverage.

**Changed**
- The app is bigger (about 25 MB more to download) because it carries the whole dictionary. The first start after this update copies the dictionary, which may take a few seconds.
- Cloud backup now checks which app version wrote your backup. If a future version saves it in a newer format, an older FluRai asks you to update instead of syncing.

**Before you update**
- If you sync FluRai on more than one phone, update every phone. Coming versions will save backups that only 2.0.0 and later can read.
