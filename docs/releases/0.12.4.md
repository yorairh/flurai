# FluRai 0.12.4

Code clean-up and a faster start.

- The app opens straight away on a phone that already has your profile. The cloud sync now catches up in the background instead of making you wait on a spinner (a new phone with no profile still checks the cloud first).
- The reading word index is built off the main thread, so the first Reading screen no longer stalls.
- Under the hood: one shared top bar, loading spinner, JLPT level list and "current user" helper replace about 40 copies; two unused pieces of code removed.
