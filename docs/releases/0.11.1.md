## FluRai 0.11.1: Email confirmation and moving progress

### New
- **Confirm your email:** new accounts get a confirmation link by email, and the app opens only after the link is used. Accounts made before this update are asked once too ("Send the email"). A mistyped address can't be confirmed: "Use a different email" deletes that unconfirmed account so you can sign up again correctly.
- **Move progress to this account:** if this phone holds study data from another account (for example one created with a mistyped email), Me and the first setup screen offer to move it to the account you're signed in with: flashcards, review history, streak days, test results, grammar progress, custom channels, level and settings.

### Notes
- Moving keeps this account's own copy where both accounts have the same card. Nothing is deleted from Firebase.
